This walkthrough demonstrates access control operations.

## Step 4: Anonymous Access

```

```

Checks public access settings.

## Permission Hierarchy

1. **Global permissions**: Site-wide settings
2. **Space permissions**: Per-space access
3. **Page restrictions**: Page-specific overrides

## Permission Types

- **View**: Can read content
- **Edit**: Can modify content
- **Comment**: Can add comments
- **Delete**: Can remove content
- **Admin**: Can manage settings

## Page Restrictions

- Restrict view to specific users/groups
- Restrict edit to specific users/groups
- Restrictions override space permissions

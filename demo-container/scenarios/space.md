# Space Management Scenario

This walkthrough demonstrates Confluence space operations.

## Step 1: List Spaces

```
List all spaces I have access to
```

Shows all spaces you can view, including the CDEMO demo space.

## Step 2: Get Space Details

```
Get details about the CDEMO space
```

Shows the space name, key, description, and other metadata.

## Step 3: View Space Homepage

```
Show me the homepage of CDEMO space
```

Each space has a homepage that serves as the main landing page.

## Step 4: Check Permissions

```
What permissions does the CDEMO space have?
```

Shows who can view and edit content in the space.

## Step 5: Page Count

```
How many pages are in the CDEMO space?
```

Gets a count of pages in the space.

## Space Types

- **Global spaces**: Visible to all users
- **Personal spaces**: Individual user spaces
- **Archived spaces**: Read-only historical content

## What You Learned

- Listing available spaces
- Getting space details
- Understanding space homepages
- Checking space permissions

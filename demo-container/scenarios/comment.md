# Comment Scenario

This walkthrough demonstrates page comment operations.

## Comment Types

- **Page comments**: General comments at the bottom of a page
- **Inline comments**: Comments attached to specific text (requires selection)

## Step 1: View Comments

```
Show me comments on the API Reference page
```

Shows existing comments on the page.

## Step 2: Add a Comment

```
Add a comment to the API Reference page: This documentation is very helpful for new developers!
```

Adds a new page comment.

## Step 3: View Your Comment

```
Show me the comment I just added
```

Retrieves the recently added comment.

## Step 4: Comment on Another Page

```
Add a comment to the Q1 Planning page: Let's schedule a review meeting for next week
```

Comments can be added to any page you have access to.

## Step 5: Delete a Comment

```
Delete the comment I added to the API Reference page
```

Removes your own comment.

## Comment Features

- @mentions notify users
- Comments support formatting
- Comments can be resolved
- Thread replies available
- Comments appear in activity

- Managing comments
- Deleting comments

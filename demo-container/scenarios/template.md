## Template Types

- **System templates**: Built-in Confluence templates
- **Space templates**: Custom space-specific templates
- **Global templates**: Organization-wide templates

## Common Templates

| Template | Use Case |
|----------|----------|
| Meeting Notes | Record meeting discussions |
| Decision | Document decisions |
| How-to Article | Step-by-step guides |
| Troubleshooting | Problem resolution |
| Product Requirements | Feature specs |

## Demo Template: Meeting Notes

```
# Meeting Notes

**Date:** [Date]
**Attendees:** [List]

## Agenda

1. Item 1
2. Item 2

## Discussion

[Notes here]

## Action Items

- [ ] Task 1 - Owner
- [ ] Task 2 - Owner
```

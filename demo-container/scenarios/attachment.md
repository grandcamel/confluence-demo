## Supported File Types

- **Images**: PNG, JPG, GIF, SVG
- **Documents**: PDF, DOC, DOCX, XLS, XLSX
- **Archives**: ZIP, TAR, GZ
- **Code**: TXT, MD, JSON, XML

## Attachment Operations

- **Upload**: Add files to pages
- **Download**: Retrieve attachments
- **Delete**: Remove attachments
- **Move**: Transfer between pages

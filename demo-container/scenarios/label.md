# Label Management Scenario

This walkthrough demonstrates content labeling operations.

## Demo Labels

The demo space uses these labels:
- `demo` - Preserved seed content
- `api` - API documentation
- `technical` - Technical content
- `guide` - User guides
- `release` - Release documentation
- `planning` - Planning documents
- `template` - Reusable templates

## Step 1: View Page Labels

```
Show me all labels on the API Reference page
```

Shows labels applied to a specific page.

## Step 2: Add a Label

```
Add the label 'important' to the Getting Started Guide
```

Adds a new label to a page.

## Step 3: Search by Label

```
Show me all pages with the label 'technical' in CDEMO
```

Finds all pages with a specific label.

## Step 4: Remove a Label

```
Remove the label 'important' from the Getting Started Guide
```

Removes a label from a page.

## Step 5: List All Labels

```
What labels exist in the CDEMO space?
```

Shows all labels used in the space.

## Label Best Practices

- Use lowercase labels
- Keep labels concise
- Create a label taxonomy
- Use labels for categorization
- Labels enable search filters

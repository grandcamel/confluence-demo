# Analytics Scenario

This walkthrough demonstrates content analytics operations.

## Step 1: View Count

```
Show me the view count for the API Reference page
```

Shows how many times a page has been viewed.

## Step 2: Watchers

```
Who is watching the Product Documentation page?
```

Lists users following the page for updates.

## Step 3: Popular Pages

```
What are the most popular pages in CDEMO?
```

Shows pages ranked by popularity/views.

## Step 4: Recent Activity

```
Show me recent activity in the CDEMO space
```

Shows recent changes and updates.

## Analytics Metrics

- **Views**: Page view count
- **Watchers**: Users following content
- **Contributors**: Users who edited
- **Last modified**: Recent changes
- **Created date**: Content age

## Using Analytics

- Identify popular content
- Find stale pages
- Track engagement
- Plan content updates
